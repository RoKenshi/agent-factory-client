# Загрузка Agent Factory

Это публичный репозиторий для установки и проверки Agent Factory. Здесь находятся только понятные
installer-скрипты, privacy/security документы, checksums и скомпилированные бинарники в Releases.
Исходный код закрытого движка и control-plane здесь не публикуется.

Agent Factory никогда не отправляет на свой сервер ключи модельных провайдеров, исходный код,
промпты, diff, пути репозитория, вывод терминала или ответы моделей. Provider key остаётся на
компьютере пользователя и используется локальным runtime только для выбранного пользователем
OpenAI-compatible endpoint.

Удалённая техническая статистика выключена по умолчанию, не содержит контента и требует отдельного
локального и серверного согласия. Точные ограничения описаны в [PRIVACY.md](PRIVACY.md).

## Установка Linux/macOS

```bash
curl -fLO https://raw.githubusercontent.com/RoKenshi/agent-factory-client/main/install.sh
less install.sh
sh install.sh
```

## Установка Windows PowerShell

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/RoKenshi/agent-factory-client/main/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1
.\install.ps1
```

Скрипт определит платформу, скачает архив из публичного GitHub Release, проверит Ed25519-подпись
`SHA256SUMS`, затем SHA-256 архива и выполнит встроенный `self-test`. Бета-релизы намеренно не
требуют платных Apple notarization и Windows Authenticode. На Windows для той же проверки Ed25519
нужен OpenSSL; установщик покажет статус Authenticode, но не заблокирует unsigned beta.

После проверки установщик сам откроет локальный мастер. Чтобы отложить настройку, задайте
`AGENT_FACTORY_SKIP_SETUP=1` (или `-SkipSetup` на Windows), а затем выполните:

```bash
agent-factory setup
```

В мастере можно добавить несколько профилей OpenRouter, DeepSeek, Ollama или любых
OpenAI-compatible endpoint. Для каждой роли выбирается пара «провайдер + модель». Новый или
заменяемый ключ сначала проверяется; профиль можно отключить или удалить. Каждая версия ключа
хранится отдельной записью только в системном хранилище учётных данных, а активный run сохраняет
свой старый обезличенный снимок маршрутизации. Codex и Claude регистрируются автоматически; для
остальных клиентов будет выдан готовый фрагмент конфигурации. Настройки, ограниченный кэш и очередь
обезличенной синхронизации находятся в одном приватном `agent-factory.json`; постоянной локальной
SQLite-базы нет. MCP сам запускает runtime. Для возврата в интерфейс используйте
`agent-factory open`.

Обычная настройка состоит из четырёх шагов: выбрать провайдера, вставить ключ, выбрать режим
«экономия / баланс / качество» и подключить автоматически найденный coding agent. Модели по ролям
назначаются автоматически. Чекбоксы конкретных моделей, custom endpoint и ручная маршрутизация
спрятаны в Advanced settings. На этой же локальной странице доступны замена ключа, статус trial,
активация Agent Factory и подключение MCP.

Наш ключ Agent Factory отделён от ключа провайдера. Он вводится командой `agent-factory activate`
и сохраняется отдельной записью в системном хранилище секретов. Оба ключа переживают перезагрузку;
первые 24 часа ключ Agent Factory не требуется.
